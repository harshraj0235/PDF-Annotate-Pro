How to Use PDF Annotate Pro 📖

Get started with our lightweight, 100% private, and local browser workspace.

01

Import your PDF

Click the PDF Annotate Pro icon in your browser popup to select a local PDF file, paste a direct PDF web URL, or drag and drop any file directly into the interface.

02

Markup and Annotate

Use the smart highlighter to mark text in tailored neon colors, drop custom text notes anywhere, draw freehand with the pen tool, or insert stamps and vector shapes (Pro).

03

Bake & Export

Click "Export PDF" in the sidebar. Our client-side rendering engine embeds all your markings natively into the PDF binary, compatible with Adobe Acrobat and standard readers.

💡 Pro Tip: Toggle **Smart Dark Mode** in the sidebar at night to read comfortable without eye strain!

Developer Implementation Guide 💻

How to implement advanced local browser tools inside PDF Annotate Pro using client-side JavaScript libraries.

📦 Recommended Client-Side Core Stack

  • PDF Rendering: pdf.js (Mozilla) — renders PDF pages onto canvas viewports.
  • PDF Generation & Modification: pdf-lib — modify, write, and export PDF binaries offline.
  • Offline OCR: tesseract.js — client-side image text extraction.

1. Dynamic PDF Merging & Splitting (100% Local)

Using pdf-lib, you can load multiple file buffers and copy pages into a single document without complex servers.

// Merge two PDF documents client-side
import { PDFDocument } from 'pdf-lib';

async function mergePDFs(pdfBuffer1, pdfBuffer2) {
  const mergedPdf = await PDFDocument.create();
  
  const doc1 = await PDFDocument.load(pdfBuffer1);
  const doc2 = await PDFDocument.load(pdfBuffer2);
  
  const copiedPages1 = await mergedPdf.copyPages(doc1, doc1.getPageIndices());
  copiedPages1.forEach((page) => mergedPdf.addPage(page));
  
  const copiedPages2 = await mergedPdf.copyPages(doc2, doc2.getPageIndices());
  copiedPages2.forEach((page) => mergedPdf.addPage(page));
  
  const mergedPdfBytes = await mergedPdf.save();
  return mergedPdfBytes; // 100% local download!
}

2. Browser-Specific Page Extraction & Deletion

Instantly select a range of pages and create a new subset PDF, ideal for students and workspace reports.

async function extractPages(pdfBuffer, pageIndicesToKeep) {
  const srcDoc = await PDFDocument.load(pdfBuffer);
  const newDoc = await PDFDocument.create();
  
  const copiedPages = await newDoc.copyPages(srcDoc, pageIndicesToKeep);
  copiedPages.forEach((page) => newDoc.addPage(page));
  
  return await newDoc.save();
}

3. Local OCR Processing (Offline Tesseract)

Implement offline OCR on scanned PDFs by converting canvas pixels into images and parsing them with Tesseract.js worker threads.

async function runOcrOnPageCanvas(canvas) {
  const worker = await Tesseract.createWorker();
  await worker.loadLanguage('eng');
  await worker.initialize('eng');
  
  const { data: { text } } = await worker.recognize(canvas);
  await worker.terminate();
  return text; // Editable OCR text extracted locally!
}
